# 02 · Wallpaper: the divergence meter

An original Steins;Gate-inspired wallpaper: eight nixie tubes reading **1.048596** in Tokyo Night colours, with worldline curves and gears. It's generated by a Python script as SVG, then rendered to PNG, so there's no copyrighted art.

## Packages in this chapter

| Package | Role |
|---|---|
| `python` | Runs `divergence.py`, which writes the wallpaper as SVG |
| `librsvg` | Provides `rsvg-convert`, which renders the SVG to PNG (also used for the GRUB/Plymouth art) |
| `hyprpaper` | Wallpaper daemon for Hyprland: shows the PNG on each monitor |

## 1. Generate

```bash
mkdir -p ~/Pictures/wallpapers/src
cp files/Pictures/wallpapers/src/divergence.py ~/Pictures/wallpapers/src/
cd ~/Pictures/wallpapers
python3 src/divergence.py > src/divergence.svg
rsvg-convert -w 1920 -h 1080 src/divergence.svg -o steins-gate-divergence.png
```

Options:
- `python3 src/divergence.py 0.571024`: a different worldline value (e.g. the Alpha line)
- `--no-caption`: drops the "WORLDLINE DIVERGENCE · STEINS GATE" caption
- `--y-shift=-170`: moves the meter up (both flags are used for the GRUB background in 09)

The default output never changes, so the wallpaper stays identical.

Design notes:
- The digits use **Noto Sans 200**, because JetBrains Mono's zero has a dot inside.
- The glow filter uses `filterUnits="userSpaceOnUse"`, so the small decimal-point dot doesn't get a clipped square glow.

## 2. Set it with hyprpaper (0.8 block syntax)

Copy [`files/.config/hypr/hyprpaper.conf`](files/.config/hypr/hyprpaper.conf). It has one `wallpaper { monitor = …; path = …; fit_mode = cover }` block **per monitor** (eDP-1 and HDMI-A-1). A monitor without a block shows no wallpaper.

```bash
pkill -x hyprpaper; hyprctl dispatch 'hl.dsp.exec_cmd("hyprpaper")'
hyprctl hyprpaper listactive     # both monitors listed
```

The same PNG is reused by hyprlock (05), SDDM (08), GRUB (09), the Chrome new tab page (04) and the Plymouth tube art (09).
