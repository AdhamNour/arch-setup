# Keybind cheat sheet

**SUPER** = Windows key. All binds live in `~/.config/hypr/hyprland.lua`.

## Apps
| Keys | Action |
|---|---|
| SUPER+Q | Terminal (kitty) |
| SUPER+R | App launcher (wofi) |
| SUPER+E | File manager (Thunar) |
| SUPER+N | Notification centre (swaync) |
| SUPER+V | Clipboard history |
| SUPER+SHIFT+Escape | System monitor (btop, floating) |

## Windows
| Keys | Action |
|---|---|
| SUPER+C | Close window |
| SUPER+F | Fullscreen |
| SUPER+CTRL+F | Maximize |
| SUPER+SHIFT+F | Toggle floating |
| SUPER+P | Pseudotile |
| SUPER+J | Toggle split direction |
| SUPER+H | Minimize (hide) |
| SUPER+SHIFT+H | Restore a minimized window (picker) |
| ALT+Tab / ALT+SHIFT+Tab | Next / previous window on this workspace |
| SUPER+←/→/↑/↓ | Move focus |
| SUPER+left-drag / right-drag | Move / resize |

## Workspaces & screens
| Keys | Action |
|---|---|
| SUPER+1…9, 0 | Go to workspace 1–10 |
| SUPER+SHIFT+1…9, 0 | Move window to workspace 1–10 |
| SUPER+S / SUPER+SHIFT+S | Show/hide scratchpad / send window to it |
| SUPER+scroll | Next / previous workspace |
| 3-finger swipe | Switch workspace |
| SUPER+SHIFT+D | Toggle external-screen-only (with external connected) |

## System
| Keys | Action |
|---|---|
| SUPER+L | Lock |
| SUPER+Escape / SUPER+M | Power menu (wlogout) |
| SUPER+Space | Switch keyboard layout (EN ↔ ع) |
| Print / SHIFT+Print / SUPER+SHIFT+Print | Screenshot full / area / window |
| SUPER+SHIFT+P | Screenshot area (no Print key) |
| Volume / mute / mic / brightness / media keys | Work, also on the lock screen |

## Terminal (kitty / tmux)
| Keys | Action |
|---|---|
| Ctrl+C | Copy if text is selected, otherwise interrupt |
| Ctrl+V | Paste |
| tmux: Ctrl+a then `\|` / `-` / `r` | Split horizontally / vertically / reload config |
